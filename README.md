# Artcraft Hub

这是一个全新的 Artcraft 资料站项目，和上级目录中的图片工具项目完全独立。

网站定位：为不会写代码、想安装和了解 Artcraft 的用户，整理官方下载入口、安装教程、功能说明，以及 Artcraft 与 Adobe 套件的基础对比。

当前确认的官方项目是：

- GitHub：<https://github.com/storytold/artcraft>
- 官方下载页：<https://getartcraft.com/>
- 官方版本页：<https://github.com/storytold/artcraft/releases>
- 官方源码安装说明：<https://github.com/storytold/artcraft/blob/main/_docs/dev_setup.md>

文档：

- [项目需求文档](docs/PRODUCT_REQUIREMENTS.md)
- [部署文档](docs/DEPLOYMENT.md)

- Vercel 项目：<https://vercel.com/emma-8abb/artcraft-hub>

正式域名：<https://artcraftphotocraft.space>（DNS 记录传播完成后即可访问；当前 Vercel 已添加该域名）。

站点必须明确标注“非官方整理站”，不能让读者误以为本网站由 ArtCraft 团队或 Adobe 运营。
